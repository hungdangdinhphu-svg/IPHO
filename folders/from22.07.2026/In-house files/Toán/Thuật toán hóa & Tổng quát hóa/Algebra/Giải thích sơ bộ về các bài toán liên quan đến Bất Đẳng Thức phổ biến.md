+) Khi ta muốn tìm S >= M; Ta có các bước sau:

B0. Biến đổi S* về S (if any)

B1. Thành lập S(x,y,z,...)

B2. Phân tích S thành S' (với S = S' với mọi x,y,z,... lớn hơn 0)

B3. Đảm bảo rằng các hạng tử của S' là dạng :

S' = (const_1)*A_1 + (const_2)*A_2 + ... + A_(n+1)

Với A_j (j thuộc 1;2;...;n) có thể áp dụng BĐT trực tiếp.

B4. Với A_j >= A_j' = A_j' = const

thì ta có:

S' >= sigma tổng từ i=1 đến n+1 cho : A_i*(const_i)
